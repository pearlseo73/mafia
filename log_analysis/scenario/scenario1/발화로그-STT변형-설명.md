# 발화 로그 STT 변형본 — 무엇을 어떻게 바꿨는가

> 작성: 2026-07-28
> 원본: [발화로그-공개.txt](발화로그-공개.txt) · [발화로그-밤마피아.txt](발화로그-밤마피아.txt) — **원본은 그대로 둔다**
> 변형본: [발화로그-공개-STT.jsonl](발화로그-공개-STT.jsonl) · [발화로그-밤마피아-STT.jsonl](발화로그-밤마피아-STT.jsonl)

원본은 사람이 손으로 쓴 깨끗한 대본이다. 실제 서비스에서 들어올 입력은 그렇지 않다. 변형본은 **실측에서 확인된 오류 유형을 시나리오 전체에 심은 것**이고, 프롬프트가 실제 입력을 견디는지 보는 데 쓴다.

[발화로그-STT실측.txt](발화로그-STT실측.txt)와 다르다. 그쪽은 사람이 실제로 브라우저에 읽어서 받은 원본 8건이고, 이쪽은 **그 오류 패턴을 전체 로그에 적용한 것**이다.

---

## 1. 형식

Redis에 들어갈 모양 그대로 한 줄에 한 건씩 담았다 (JSON Lines).

```
{ "t":"21:00:08", "speaker":"라면왕", "round":1, "phase":"DAY_DISCUSSION", "text":"..." }
```

| 파일 | 대응 Redis 키 |
|---|---|
| 발화로그-공개-STT.jsonl | `utt:{roomId}:public` |
| 발화로그-밤마피아-STT.jsonl | `utt:{roomId}:night` |

`phase` 값은 원본 로그와 같은 이름을 쓴다 — `DAY_START` · `DAY_DISCUSSION` · `DAY_VOTE` · `FINAL_DEFENSE` · `AI_JUDGMENT` · `RESULT` · `NIGHT`.

**`phase`가 새로 생긴 필드다.** 서버가 시점의 주인이므로 발화를 받을 때 서버가 붙인다. 이게 있으면 "저는 딸기우유 씨입니다"가 자기소개가 아니라 투표 선언임을 AI가 알 수 있다.

**`speaker`는 오염시키지 않았다.** 각자 자기 브라우저에서 자기 마이크만 인식하므로 화자는 서버가 세션에서 확실히 안다. 흔들리는 것은 **발화 안에서 남을 지칭한 이름**뿐이다.

---

## 2. 닉네임 매핑

한국인 사용자가 실제로 지을 만한 2~8자 한글 닉네임으로 바꿨다. 화자 이름과 대화 중 지칭을 모두 교체했다.

| 원본 | 닉네임 | 역할(참고) |
|---|---|---|
| 김서준 | **라면왕** | 시민 |
| 강예린 | **딸기우유** | 마피아 |
| 정민재 | **곰돌이** | 시민 |
| 이하윤 | **밤하늘** | 시민 |
| 박도현 | **초코비** | 마피아 |
| 최지우 | **소금빵** | 시민 |

닉네임을 실명에서 바꾼 이유는 **실제 서비스가 실명을 쓰지 않기 때문**이다. 그리고 닉네임은 사전에 없는 단어라서 오인식 양상이 실명과 다르다.

---

## 3. 심은 오류 — 네 가지 유형

### 3-1. 이름 오인식

같은 사람을 가리키는데 표기가 갈린다. **한 발화 안에서도 갈린다** (실측에서 실제로 그랬다).

| 닉네임 | 잘못 인식된 형태 | 나온 곳 |
|---|---|---|
| 라면왕 | 라멘왕 · 라면 왕 | 21:00:40 · 21:07:53 |
| 딸기우유 | 달기우유 · 딸기유유 | 21:01:12 · 21:06:20 |
| 곰돌이 | 공돌이 | 21:07:05 |
| 밤하늘 | 밥하늘 | 21:00:57 |
| 초코비 | 초코피 · 초코 비 | 21:02:50 · 21:13:10 · 21:04:05 |
| 소금빵 | 소금방 | 21:01:52 · 21:05:05 |

### 3-2. 단어가 다른 말로 바뀜 — 뜻이 사라지거나 뒤집힘

실측에서 나온 것을 그대로 옮겼고, 같은 성격의 것을 몇 개 더 심었다.

| 시각 | 원본 | 변형 | 무엇이 사라졌나 |
|---|---|---|---|
| 21:04:08 | 저 방어권 있습니다 | 저 **방학과** 있습니다 | 방어권 주장 |
| 21:01:12 | 넣을 생각입니다 | **너를** 생각입니다 | 투표 의사 |
| 21:10:23 | 찬성했습니다 | **편성**했습니다 | **자기모순의 근거** |
| 21:00:15 | 시간 낭비 | 시간 **남비** | 키워드 뽑기 대상 표현 |
| 21:00:31 | 삼분 동안 / 다들 시민이라고 | **3년** 동안 / 근데 **신**이라고 | 시민 주장 |
| 21:09:07 | 마피아였네요 | 마피아 **없네요** | **뜻이 정반대** |

`편성했습니다`와 `마피아 없네요`가 특히 고약하다. **둘 다 정상적인 한국어라서 사전 교정으로 잡을 근거가 없다.**

### 3-3. 짧은 발언이 엉뚱한 단어로

| 시각 | 원본 | 변형 |
|---|---|---|
| 21:00:04 | 어 시작됐네요 | 이 시작했네요 |
| 21:03:28 | 다들 넣었나요 | **다 들었나요** |
| 21:09:55 | 이제 셋이네요 | 이제 **세 시**네요 |
| 21:04:32 (밤) | 네 제가 지정할게요 | **내** 제가 지정할게요 |
| 21:09:18 (밤) | 혼자 남았네 | 혼자 **났네** |

짧을수록 취약하다. 실측에서 `네` → `그때` 가 나왔다.

### 3-4. 문장이 합쳐지거나 끊김

**합쳐지는 쪽이 실제 모습이다.** 실측에서 대본 9건이 8건으로 왔다 — 쪼개진 게 아니라 두 발언이 한 건이 됐다.

| 원본 두 건 | 변형 | 비고 |
|---|---|---|
| 21:02:36 + 21:02:45 (곰돌이) | 21:02:45 한 건 | 아이템 결과 공유가 잡담과 붙었다 |
| 21:06:15 + 21:06:20 (초코비) | 21:06:20 한 건 | **아래 4-2 참조 — 가장 중요한 변화** |
| 21:09:30 + 21:09:33 (밤, 초코비) | 21:09:33 한 건 | |

끊기는 경우도 하나 넣었다.

| 원본 한 건 | 변형 |
|---|---|
| 21:08:50 딸기우유 "초코비 씨 지금 저 버리는 거예요" | 21:08:50 "초코비 씨 지금" + 21:08:52 "저 버리는 거예요" |

합쳐진 발화의 `t`는 **뒤쪽 발화의 시각**을 쓴다. STT는 말이 끝난 뒤에 결과를 주므로 도착 시각이 뒤에 찍힌다.

### 3-5. 그 밖에

- **숫자는 알아서 정규화된다** — "일라운드"라고 말해도 `1라운드`로 적힌다 (21:11:20 · 21:11:45). 실측에서 확인된 것이고, 이건 오류가 아니라 도움이 되는 쪽이다
- 붙여쓰기 오류 — `쓴게`, `처형하는데`
- 어미 변형 — `죽이나요` → `죽이다니요`

## 4. 이 변형이 각 기능에 주는 영향

### 4-1. 진술대조권 — 3단 모순 중 하나가 손상됐다

초코비(원 박도현)의 강예린 관련 진술 세 개가 이렇게 됐다.

| 라운드 | 상태 |
|---|---|
| R1 "제일 수상해요" | **남았다.** 다만 뒤쪽이 `달기우유`·`너를 생각입니다`로 깨졌다 |
| R2 "처음부터 믿었습니다" | **남았다.** 다만 `딸기유유`로 이름이 갈렸고 앞 발화와 합쳐졌다 |
| R3 "의심한 적이 없습니다" | **깨끗하게 남았다** |
| R3 "처형에 찬성했습니다" | **사라졌다** — `편성했습니다`가 되어 자기모순의 근거가 없다 |

실측 검증에서 **`u2`(R1 발언)를 세 번 다 놓쳤다.** 이 변형본에서도 같은 일이 일어나는지, 그리고 원인이 이름인지 문장 파손인지를 보는 게 다음 확인 사항이다.

### 4-2. 21:06:20 이 새로 생긴 문제다

원본에서는 두 발화였다.

```
21:06:15  마음이 바뀐 겁니다 그게 이상한가요          ← 모순으로 잡으면 안 되는 것
21:06:20  저는 처음부터 강예린 씨를 믿었습니다        ← 반드시 잡아야 하는 것
```

변형본에서는 **한 발화**다. 발화 번호가 하나뿐이니 AI가 이걸 잡으면 "잡아야 할 것을 잡았다"와 "잡으면 안 되는 것을 잡았다"가 동시에 성립한다. 화면에 인용문으로 나갈 때도 해명과 모순이 한 덩어리로 붙어서 나간다.

**이건 프롬프트로 풀 문제가 아니라 발화 경계 문제다.** 지금 검증 체계(볼 포인트 `u5`를 잡지 않았는가)로는 판정할 수 없다.

### 4-3. 키워드 뽑기 — 뽑을 표현이 줄었다

딸기우유(원 강예린) R1 발화에서 `시간 낭비`가 `시간 남비`가 됐다. 환각 방어는 **원문 부분 문자열 검사**라서 `시간 남비`는 통과한다. 원문에 그렇게 있으니까. **즉 오인식된 단어가 키워드로 그대로 나간다.** 유저는 상대가 하지 않은 말을 키워드로 보게 된다.

`억울하면`·`비효율적`은 온전하다.

### 4-4. 밤 로그 유출 검사기를 손봐야 한다

[UtteranceLog.assertNoNightLogLeak](../../../ai-lab/src/test/java/com/ssafy/mafia/ailab/fixture/UtteranceLog.java)은 밤 로그 문구를 문자열로 박아두고 검사한다. 변형본에서 그 문구 중 셋이 달라졌다.

| 검사 문구 | 변형본 | 검사 가능? |
|---|---|---|
| 그래야 안 걸려요 | 그대로 | ✅ |
| 오늘 누구 죽일까요 | 그대로 | ✅ |
| 신문도 손볼게요 | 그대로 | ✅ |
| 눈치챈 것 같은데 | 그대로 | ✅ |
| 제가 지정할게요 | `내 제가 지정할게요` 안에 포함 | ✅ |
| 최지우로 하죠 | **소금방으로 하죠** | ❌ |
| 혼자 남았네 | **혼자 났네** | ❌ |
| 이하윤으로 하자 | **밤하늘로 하자** | ❌ |

변형본을 쓰는 테스트를 만들 때는 **문구 목록을 이 파일 기준으로 다시 넣어야 한다.** 안 그러면 유출을 못 잡는데 통과한 것처럼 보인다.

## 5. 아직 안 한 것

- **이 변형본을 읽는 로더가 없다.** 기존 픽스처 로더는 `[시각] R1/PHASE 화자: 발화` 형식을 파싱한다. JSON Lines를 읽으려면 별도 로더가 필요하다
- **이름만 교정한 대조군**을 만들지 않았다. 서버가 닉네임 사전으로 이름을 고쳐주면 판정이 회복되는지 보려면 그 버전이 필요하다
- 원본에는 없는 오류 유형 두 가지를 아직 안 넣었다 — **여러 사람이 겹쳐 말할 때의 에코**(남의 말이 내 발화로 들어감)와 **발화 유실**(Chrome이 조용할 때 인식을 끊는 것)
