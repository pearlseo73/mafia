# 게임 로그 픽스처 — 시나리오 설정

> 최종 수정: 2026-07-26
> 용도: 로그 분석 LLM 기능(조간신문·AI 심판·진술대조·키워드 뽑기·칭호) 개발용 예시 데이터
> 관련 문서: [기능명세서.md](../../docs/기능명세서.md) · [AI기능-구현설계.md](../../docs/AI기능-구현설계.md)

Redis 연결 전까지 사용할 **샘플 게임 로그**의 설정이다. 6인 게임, 마피아 2 · 시민 4.

---

## 1. 플레이어별 보유 아이템

| # | 이름 | 역할 | 보유 아이템 | 개수 |
|---|---|---|---|---|
| 1 | **김서준** | 시민 | `STATEMENT_COMPARE` 진술대조권<br>`KEYWORD_EXTRACT` 키워드 뽑기 | 2 |
| 2 | **이하윤** | 시민 | `VOTE_DOUBLE` 자기 표 두표로 계산 | 1 |
| 3 | **박도현** | **마피아** | `NEWSPAPER_EDIT` 조간신문 조작권<br>`BOMB_DEFENSE` 폭탄 방어권 | 2 |
| 4 | **최지우** | 시민 | — | 0 |
| 5 | **정민재** | 시민 | `SILENCE` 침묵<br>`STATEMENT_COMPARE` 진술대조권<br>`KEYWORD_EXTRACT` 키워드 뽑기 | 3 |
| 6 | **강예린** | **마피아** | `SILENCE` 침묵 | 1 |

- 아이템 **6종이 모두 배분**되었고, 보유 개수는 0~3개 범위를 지켰다 (0, 1, 1, 2, 2, 3)
- 역할 제한 준수 — 시민 전용(`STATEMENT_COMPARE`, `VOTE_DOUBLE`)은 시민에게만, 마피아 전용(`NEWSPAPER_EDIT`)은 박도현에게만

### 아이템 코드

[AI-API명세.md](../../docs/AI-API명세.md)와 동일한 코드를 사용한다.

| 코드 | 이름 | 보유 제한 | 사용 시점 |
|---|---|---|---|
| `STATEMENT_COMPARE` | 특정인 지목 진술대조권 | 시민만 | 토론 |
| `KEYWORD_EXTRACT` | 특정인 지목 키워드 뽑기 | 전원 | 토론 |
| `SILENCE` | 원하는 사람 말 못하게 하기 | 전원 | 토론 |
| `VOTE_DOUBLE` | 자기 표 두표로 계산 | 시민만 | 투표 |
| `NEWSPAPER_EDIT` | 조간신문 조작권 | 마피아만 | 밤 |
| `BOMB_DEFENSE` | AI 심판의 폭탄 방어권 | 전원 | 패시브 (심판 지목 시) |

## 2. 캐릭터별 로그 특성 (의도적 설계)

이 픽스처의 목적은 LLM 기능 검증이므로, **각 캐릭터가 특정 기능의 테스트 케이스가 되도록** 발화를 설계한다.

| 이름 | 발화 특성 | 검증하는 기능 |
|---|---|---|
| 박도현 (마피아) | 1라운드와 3라운드 알리바이가 어긋남 | **진술대조권** — 실제 모순이 있어야 검증 가능 |
| 강예린 (마피아) | 공격적으로 시민 몰이, 발화량 많음 | **키워드 뽑기** |
| 최지우 (시민) | 거의 말하지 않음 (2~3마디) | **환각 방어** — "분석할 발언이 부족" 폴백 |
| 이하윤 (시민) | 시민에게 계속 투표 (오판) | **칭호** — 팀킬 지표 |
| 김서준 (시민) | 추리 주도, 논리적 | 조간신문 인용 소재 |
| 정민재 (시민) | 아이템 적극 사용 | 아이템 사용 로그 |

## 3. 3라운드 시나리오 (시민 승)

| 라운드 | 낮 | 밤 | 생존 |
|---|---|---|---|
| **1** | 투표 동률 → **AI 심판** → 박도현 지목 → **방어권 발동, 처형 무효** (명세 20-6) | 최지우 사망 | 2M 3C |
| **2** | 강예린 최다득표 → 최후변론 → 찬성 과반 → **처형** | 이하윤 사망 | 1M 2C |
| **3** | 박도현 최다득표 → 최후변론 → **처형** | — | **0M 2C → 시민 승** (명세 13-7) |

### 승리 조건 검증

명세 13-6(마피아 수 == 시민 수 → 마피아 승) / 13-7(마피아 전멸 → 시민 승)을 각 사망 시점마다 확인했다.

| 시점 | 마피아 : 시민 | 판정 |
|---|---|---|
| 게임 시작 | 2 : 4 | 계속 |
| 1라운드 AI 심판 (방어권으로 사망 없음) | 2 : 4 | 계속 |
| 1라운드 밤 — 최지우 사망 | 2 : 3 | 계속 (한 명만 더 죽으면 마피아 승) |
| 2라운드 낮 — 강예린 처형 | 1 : 3 | 계속 |
| 2라운드 밤 — 이하윤 사망 | 1 : 2 | 계속 |
| 3라운드 낮 — 박도현 처형 | 0 : 2 | **시민 승 (13-7)** |

### 아이템 사용 계획

**모든 아이템을 소진하지 않는다.** 5개만 사용하고 3개는 미사용으로 남긴다.

| 사용 시점 | 사용자 | 아이템 | 대상 |
|---|---|---|---|
| 1라운드 토론 | 정민재 | `KEYWORD_EXTRACT` | 강예린 |
| 1라운드 투표 | 이하윤 | `VOTE_DOUBLE` | — |
| 1라운드 AI 심판 | 박도현 | `BOMB_DEFENSE` | (패시브 자동 발동) |
| 1라운드 밤 | 박도현 | `NEWSPAPER_EDIT` | — |
| 2라운드 토론 | 강예린 | `SILENCE` | 김서준 |
| **3라운드 토론** | 김서준 | `STATEMENT_COMPARE` | 박도현 |

> `STATEMENT_COMPARE`를 3라운드에 배치한 이유: 1라운드에는 **대조할 이전 발화가 없다.** 박도현의 모순이 1↔2↔3라운드에 걸쳐 누적되므로 3라운드에 써야 실제로 모순이 검출되고, 그 결과가 박도현 처형으로 이어지는 인과가 성립한다.

**미사용 잔여 3개** — 정민재의 `STATEMENT_COMPARE`·`SILENCE`, 김서준의 `KEYWORD_EXTRACT`

두 사람 모두 생존하므로 명세 16-10(사망 시 보유 아이템 전부 사용 완료 처리)은 적용되지 않는다. 오히려 **아이템 사용 횟수가 사람마다 다른 편이 칭호 지표 검증에 유리하다.**
