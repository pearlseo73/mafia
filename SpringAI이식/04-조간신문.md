## 1. 입력

| | | 왜 |
|---|---|---|
| 로그 소스 | `utt:{roomId}:public` **만** | 밤 로그가 새면 마피아 신원 노출 (TC-12 = 최우선 회귀 테스트) |
| 라운드 범위 | **직전 라운드의 낮 전체** | 제1호 = R1 낮 |
| `phase` | **화이트리스트 4종** — `DAY_DISCUSSION` · `DAY_VOTE` · `AI_JUDGMENT` · `FINAL_DEFENSE` | 아래 |
| 화자 | **전원** | 진술대조·키워드와 반대다. 회의 전체를 요약한다 |
| 발화 번호 | **없다** | 평문 출력이라 번호를 되받을 계약이 없다 |
| 결과 한 줄 | `결과: {이름} 처형` 또는 `결과: 처형 없음 ({사유})` | 서버가 아는 사실을 안 주면 모델이 추측한다 |
| 역할 정보 | **넣지 않는다** | 절대 규칙 2. 이벤트의 `role=마피아` 는 코드가 받아서 렌더에서 버린다 |
| 득표 수치 · 생존자 목록 | 넣지 않는다 | 🔴 §8 미결 |

### `DAY_START` 와 `RESULT` 를 뺀 이유가 서로 다르다

- **`DAY_START`** — 어제 신문에 대한 반응("근데 신문 내용이 좀 이상한데요")이라 **신문이 자기 얘기를 인용하게 된다**
- **`RESULT`** — 처형 반응이라 사망자 줄과 겹치고, **생성 창을 3초 더 깎는다**

### 컷오프는 코드로

`phase` 화이트리스트로 자른다. 여기에 `phase != NIGHT` assert 를 **한 겹 더** 둔다 (§5).

라운드별 실측 크기: **R1 낮 28건 780자 · R2 25건 681자 · R3 19건 427자.**

## 2. 렌더 — 🔴 한 줄에 이름이 둘이면 주체가 뒤집힌다

```
[21:02:00] 토론 · 말한사람 밤하늘 · 발언 소금빵 씨는 계속 조용한데 이것도 전략일 수 있어요
[21:03:45] 심판 · 말한사람 라면왕 · 발언 동률이라 AI 심판으로 넘어갔네요
결과: 처형 없음 (방어권_발동)
```

형식: `[{t}] {페이즈라벨} · 말한사람 {speaker} · 발언 {text}` — 마지막에 결과 한 줄.

**2026-07-30 실측** — `21:02:00` 이 2회 연속 "소금빵이 경고했다"로 나왔는데, 실제로는 **밤하늘이 소금빵을 지적한 말**이었다. 한 줄에 이름이 둘(화자 + 언급 대상) 있으면 모델이 주체를 뒤집는다. `말한사람` · `발언` 라벨로 끊어서 고쳤다.

**발언을 따옴표로 감싸지 않는다.** 본문 인용 상한과 충돌해서 모델이 입력의 따옴표를 인용 허가로 읽는다.

> AI 심판·칭호는 `화자: 발화` 형식을 쓴다 (프롬프트 문안이 그렇게 선언돼 있다). 같은 문제가 잠재하지만 판결 이유는 "이 참가자"로만 쓰게 되어 있어 영향이 작다.

## 4. 🔴 밤 로그 유출 검사 (TC-12) — 호출 함수 **안**에 둔다

**CLAUDE.md 의 "문자열 검사 자동화" 예외 한 건이다.** 눈으로는 놓치고, 한 줄만 새면 마피아 신원이 그대로 노출된다.

### 검사 방식

```
① 밤 로그에서 어절을 모은다
② 낮 로그에도 나오는 어절을 뺀다   ← 이게 핵심
③ 4자 이상만 남긴다
④ 남은 어절이 입력·출력에 있는지 검사한다 (양쪽 다)
```

**교집합을 빼지 않으면 "생각해요" 같은 것이 매 회차 걸려서 검사가 무시당한다. 검사는 조용해야 쓸모가 있다.**

불리언이 아니라 **걸린 어절 목록**을 돌려준다 — 어디서 샜는지 보이게.

### 두 겹으로 둔다

1. `assert phase != NIGHT` — 컷오프가 샌 경우를 **코드로** 먼저 막는다. 문자열 검사보다 정확하다
2. 어절 검사 — 입력·출력 양쪽

**검사를 호출 함수 안에 넣는 이유는 TC-12 가 최우선 회귀 테스트라 빼먹을 수 없게 하려는 것이다.**

> ⚠️ **검사 문구는 STT 변형본 기준으로 다시 넣어야 한다.** 원본 밤 로그와 변형본에서 문구 셋이 달라졌다 (`소금빵으로 하죠` → `소금방으로 하죠` 등). 안 그러면 유출을 못 잡는데 통과한 것처럼 보인다. [fixture/발화로그-밤마피아-STT.jsonl](fixture/발화로그-밤마피아-STT.jsonl) 을 쓴다.

### 🔴 TC-12b — 입력이 깨끗해도 발생한다

**밤 로그를 한 줄도 주지 않았는데** 제1호 본문이 이렇게 나왔다.

```
마지막까지 정체를 숨긴 초코비는 …          ← 초코비는 실제 마피아다
```

입력의 `AI 심판 지목 + 방어권 생존` 조합을 모델이 서사로 엮은 것이라 **입력 필터로는 못 막는다.** 프롬프트 규칙("누가 마피아인지 판단하지 않는다")도 못 걸렀다.

금지 표현 후보 — `정체를 숨긴` · `진짜 마피아` · `베일` · `미궁` · `여전히 감춰진`, 성별 추정(`그녀` · `그의`). **문자열 검사를 붙일지는 미결이다** — 표현이 계속 바뀌면 목록으로 못 잡으므로 회차를 늘려 같은 표현이 반복되는지부터 본다.

## 6. 🔑 2단 조립 — 조작을 구조로 막는다

**LLM 이 만드는 것은 본문(`body`)뿐이다.** 나머지는 서버가 붙인다.

| 조각 | 만드는 주체 | 시점 |
|---|---|---|
| 머리글 `【601 조간】 제N호` | **서버** | 항상 |
| 본문 | LLM | 낮 결과 확정 직후 |
| 사망자 줄 · 처형·역할 공개 | **서버** | **아침** |

```
밤   →  머리글 + 본문             ← 조작권 소지자에게 보여주는 것이 이것 그대로
아침 →  머리글 + 사망자 줄 + 본문   ← 전원에게
```

### 왜 이렇게 나누는가

- **밤에는 사망자 줄을 만들 수 없다** — 밤 살해가 아직 안 일어났다
- 그래서 **처형·역할 관련 조작이 구조적으로 무효화된다.** 조작권이 닿는 것은 토론 요약뿐이다
- 사망자 줄이 앞에 오는 이유는 17-6 — 낮 시작에 10초만 표시한다
- **LLM 실패 시 사망자 줄만 나가도 정보 손실이 없다.** 잃는 것은 재미뿐이다
- 호수를 서버가 붙이면 **모델이 틀릴 일이 없어진다**

### 서버가 만드는 줄

```
■ {밤 사망자} 님이 마피아에게 살해당했습니다.
■ {처형자} 님 처형 — {역할}였다
■ 평화로운 밤이었습니다              ← 둘 다 없을 때 (17-7, 문구 미결)
```

**호수 = 기반이 된 낮의 라운드 번호.** R1 낮 → R2 아침에 제1호. 첫째 날 아침은 게임 시작 직후라 신문이 없다.

**역할 공개 주체가 서버로 단일화된다** — LLM 프롬프트에는 역할을 주지 않는데 처형된 사람의 역할은 공개해야 하므로, 이 줄만 서버 템플릿으로 만든다.

## 8. 🔴 이식과 함께 결정할 것

### ① ~~결과 줄에 득표를 넣을지~~ → **넣지 않는다 (2026-07-31 확정)**

결과 줄은 지금 그대로 `결과: {이름} 처형` / `결과: 처형 없음 ({사유})` 만 준다.

**감수하는 것을 알고 있어야 한다.** 득표를 안 주면 모델이 결과를 추측하고, 추측이 사실과 반대로 나온 회차가 실제로 있었다.

```
■ "시간 낭비"라는 딸기우유 님, 초코비 님의 지목으로 위기 맞아
```

실제 R1 투표는 `초코비=2 라면왕=2 소금빵=2 딸기우유=1` 로 **딸기우유가 최저 득표**다. 결과 줄이 `처형 없음 (방어권_발동)` 뿐이라 모델이 토론 분위기로 결과를 추측했다.

**신문이 시민을 오도할 수 있는 상태로 간다는 뜻이다.** 게임 설계상 신문은 원래 마피아가 조작하는 매체이므로 "신문을 100% 믿을 수 없다"가 규칙 안에 있고, 그래서 감수 가능한 쪽이다.

**돈 안 드는 완화 하나** — 프롬프트에 `주어진 결과 줄 밖의 투표 결과를 쓰지 않는다` 를 한 줄 넣는 것. 이미 "주어진 발언 밖의 사실은 쓰지 않는다"가 있는데 **투표 결과에는 안 걸렸다.** 회차를 늘려 같은 오류가 반복되면 그때 붙인다.

### ② 인용이 진술대조 증거를 노출한다

상한 1~3개를 지켰는데도 **3개를 다 쓰면 `u2`(진술대조 TC-1 의 근거 발화)가 그대로 나갔다.** 상한을 2개로 줄일지, 인용을 짧게 자르도록(`"제일 수상하다"`) 지시할지 골라야 한다.

### ③ 커버리지 — 6명 중 3명이 안 나온 회차가 있다

제1호 1회분에서 라면왕·밤하늘·소금빵이 아예 등장하지 않았다. **아침에 붙는 사망자 줄이 소금빵인데 본문에 소금빵이 없으면 두 헤드라인이 서로 무관해진다.** 프롬프트로 "전원 언급"을 지시하면 요약문으로 돌아가므로 회차를 늘려 빈도부터 본다.

### ④ R2·R3 미검증

**제1호 1회분만 봤다.** 제2호(처형·역할 공개)와 제3호(무사망)를 아직 안 돌렸다.

## 9. 조작권 (17-4 · 17-5, TC-15)

- **LLM 재호출이 없다.** 텍스트 치환이다
- 마피아 + 밤 phase + 조작권 보유 검증
- 500자 초과 시 400
- **본문이 없으면(폴백) 요청을 거부하고 아이템을 소모시키지 않는다**
- 성공 시 아이템을 사용 완료로 전이
- 편집 중 상태는 서버에 저장하지 않는다

**`preview` 는 마피아 전원이 아니라 조작권 소지자 한 명에게만** 간다 (명세 17-3 수정 요청). 전원에게 주면 시민이 상시 불리해진다.
