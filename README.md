# 🎭 화상 마피아 - AI 실험 레포지토리

화상 기반 마피아 게임 프로젝트의 **AI 기능 검증·프로토타이핑** 저장소입니다.

> 📌 이 레포는 **AI 파트 담당자의 실험 공간**입니다.
> 팀 전체 프로젝트(프론트·백엔드 포함) 레포지토리는 추후 별도로 생성됩니다.
> 여기서는 게임에 넣을 AI 기능들이 **실제로 구현 가능한지** 를 먼저 검증합니다.

---

## 🎯 목적

본 게임에 들어갈 AI 기능의 **실현 가능성 검증** 및 **프로토타이핑**:

1. **음성 로그 분석 (STT + LLM)**
   - 사용자 대화를 STT로 텍스트화하여 게임 로그로 저장
   - 📰 **조간신문**: 매일 아침 밤사이 사건과 토론을 요약한 기사 자동 발행
   - ⚖️ **AI 심판**: 발언의 모순·회피·투표 패턴을 분석해 마피아 의심도 추정
   - 🔍 **진술 분석 아이템**: 특정 사용자를 지목해 그 사람의 발언을 집중 분석

2. **얼굴/표정 분석 (MediaPipe 등)**
   - 최후 변론 시 최다 득표자의 얼굴을 확대
   - 표정(blendshape) 기반 감정 분석 및 **"AI 동요 지수"**(연출용) 표시
   - (실험) rPPG 심박 추정으로 긴장 연출

> ⚠️ 표정·심박 기반 지표는 **오락용 연출**이며, 과학적 거짓말 탐지가 아닙니다.

## 🏗️ AI 기능의 목표 아키텍처 (참고)

실제 서비스에서 AI 파트가 어떻게 붙을지에 대한 구상:

```
Vue (WebRTC)  ──  브라우저 MediaPipe JS로 실시간 얼굴 랜드마크 (서버 부하↓)
   │
Spring Boot (게임 로직·세션)  ──REST/gRPC──►  FastAPI (Python AI 서비스)
                                                ├─ STT (faster-whisper)
                                                ├─ LLM 로그 분석
                                                └─ 표정/감정/심박 분석
```

- **AI 기능은 Python(FastAPI) 마이크로서비스**로 분리 (ML 생태계가 Python 중심)
- Spring Boot(백엔드) ↔ Python 서비스는 REST/gRPC로 연동

- **`Utterance` 로그 스키마**가 STT·LLM 세 기능의 공통 입력 → 가장 먼저 확정할 것

- 실시간 웹캠 파이프라인(WebRTC↔서버) 지연이 최대 리스크 → 초기 PoC 권장
