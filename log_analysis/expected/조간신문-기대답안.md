# 기대답안 — 조간신문 (Task 17)

> 최종 수정: 2026-07-30
> 프롬프트: [조간신문.md](../prompts/조간신문.md) · 노트북: [log_prompting.ipynb](../../log_prompting.ipynb) `# 3. 조간신문`
> 픽스처: [발화로그-공개-STT.jsonl](../scenario/scenario1/발화로그-공개-STT.jsonl) · [게임이벤트.txt](../scenario/scenario1/게임이벤트.txt)

**문장이 그대로 나와야 한다는 뜻이 아니다.** 창작이고 `temperature=0.8`이라 회차마다 달라진다. 아래는 "이런 모양이면 성공"의 참조 샘플이고, 실제 확인은 각 절의 **볼 포인트**로 한다.

자동으로 검사하는 것은 **밤 로그 유출**(TC-12)과 **500자 초과** 둘뿐이다.

---

## 1. 제1호 — 실제 출력 1회분 (07-30, 검증 완료)

R1 낮 28건 780자 + `결과: 처형 없음 (방어권_발동)` → `gpt-4o-mini` · `temperature=0.8` · `max_tokens=300`

```
【601 조간】 제1호

■ "시간 낭비"라는 딸기우유 님, 초코비 님의 지목으로 위기 맞아

"저는 그런 거 시간 낭비라고 생각해요." — 딸기우유 님의 발언이 회의장을 뒤흔들었다.
순간, 곰돌이 님은 "느낌으로 가면 시민만 죽어요"라며 반격했고, 초코비 님은
"딸기우유 씨가 제일 수상해요"라며 의심의 화살을 돌렸다. 분위기는 덮어놓고
진행하자는 딸기우유 님과, 신중한 접근을 요구하는 곰돌이 님 사이에서 긴장감이
감돌았다.

결국 투표는 동률로 끝났고, AI 심판의 호출로 이어졌다. 초코비 님의 이름이
호명되었지만, 방어권이 발동돼 처형은 이루어지지 않았다. 회의는 다시 원점으로
돌아가며 불안감이 더해졌다.
```

330자 · 형식은 전부 통과 (헤드라인 1개 + 본문 2문단 · 인용 3개 · 님 호칭 · 500자 이내 · 밤 로그 유출 없음 · 역할 판단 없음 · 성별 추측 없음).

### 맞은 것 — 인용 3개와 결과 문단

| 기사 | 원문 | |
|---|---|---|
| "저는 그런 거 시간 낭비라고 생각해요." | `21:00:15` 딸기우유 (STT 원문은 `시간 남비`) | ✅ 교정 인용 |
| "느낌으로 가면 시민만 죽어요" | `21:00:23` 곰돌이 — 글자 그대로 | ✅ |
| "딸기우유 씨가 제일 수상해요" | `21:01:12` 초코비 — 글자 그대로 | ✅ |
| 동률 → AI 심판 | `21:03:45` 라면왕 발화 | ✅ |
| 초코비 호명 · 방어권 | `21:04:05` 곰돌이 · `21:04:08` 초코비 + 결과 줄 | ✅ |

STT가 깨진 `초코 비`·`방학과`를 제대로 복원했다. 큰따옴표 안의 `시간 남비` → `시간 낭비` 교정은 **의도한 것이 아니라 관찰된 것이다** — 신문은 요약이라 교정이 자연스럽지만, 유저가 실제 발언과 대조할 수 있는 유일한 지점이라 남겨둘지 정해야 한다.

### 🔴 틀린 것 — 헤드라인

```
■ "시간 낭비"라는 딸기우유 님, 초코비 님의 지목으로 위기 맞아
```

실제 R1 투표는 `초코비=2 라면왕=2 소금빵=2 딸기우유=1`로 **딸기우유가 최저 득표**다. 위기에 몰린 것은 호명당한 초코비이고, 초코비는 "딸기우유한테 넣겠다"고 말한 뒤 실제로는 소금빵에게 투표했다.

**입력에 득표가 없어서 모델이 추측한 것이다.** → [프롬프트 §9 미결 1](../prompts/조간신문.md)

### ⚠️ 근거 없는 문장 2개

- `회의는 다시 원점으로 돌아가며 불안감이 더해졌다` — 대응 발화가 없다. "주어진 발언 밖의 사실을 쓰지 않는다"에 걸리는 창작
- `덮어놓고 진행하자는 딸기우유 님` — 본인 말은 "느낌으로 가야죠"·"방식이 비효율적이라고 한 거잖아요"다. 방향은 맞지만 본인보다 세게 요약됐다

### ⚠️ 놓친 것 — 6명 중 3명이 안 나왔다

라면왕·밤하늘·소금빵이 등장하지 않는다. 빠진 것이 전부 다음 라운드에 다시 쓰인다.

| 빠진 발화 | 어디서 다시 쓰이나 |
|---|---|
| `21:00:40` 밤하늘 → 라면왕 진행 주도 의심 | 초코비가 `21:00:57`에 얹는 출발점 |
| `21:02:00` 밤하늘 → 소금빵의 침묵 지적 | — |
| `21:02:50` 소금빵 → 초코비 지목 | R2 토론 `21:05:05`의 핵심 근거 |
| `21:03:10` 밤하늘의 2표 아이템 선언 | — |

특히 아침에 붙는 사망자 줄이 소금빵인데 본문에 소금빵이 없어 **헤드라인 두 줄이 서로 무관해진다.**

## 2. 볼 포인트 — 회차마다 이것만 본다

- **헤드라인 두 줄만 읽어도 성립하나** (10초만 표시한다)
- **결과 문단이 실제와 맞나** — 동률/처형/방어권. 위 1번처럼 득표를 추측하지 않았나
- **인용이 원문에 있나**, 몇 개인가 (상한 3개), 진술대조 증거를 통째로 뿌리지 않았나
- **등장인물 수** — 절반 이하면 기록해둔다
- **판정하는 문장이 없나** (아래 4번)
- 밤 로그 유출 · 500자는 코드가 본다

## 3. 아침 조립본 · 폴백 · 조작본

### 아침 조립본 (전원)

서버가 사망자 줄을 앞에 붙인 것. 본문은 밤에 조작된 상태 그대로다.

```
【601 조간】 제1호

■ 소금빵 님이 마피아에게 살해당했습니다.
■ "시간 낭비"라던 딸기우유 님, 하루 만에 최다 지목자로

...(본문)
```

제2호는 두 줄이 함께 나간다 — 밤 살해가 위, 처형이 아래.

```
■ 밤하늘 님이 마피아에게 살해당했습니다.
■ 딸기우유 님 처형 — 마피아였다
```

제3호는 밤 사망자가 없다.

```
■ 초코비 님 처형 — 마피아였다
```

**무사망 라운드가 픽스처에 없다** — `■ 평화로운 밤이었습니다` 분기는 아직 못 태웠다 ([체크리스트 §7](../scenario/scenario1/테스트-체크리스트.md)).

### 폴백 (LLM 실패)

```
【601 조간】 제1호

■ 소금빵 님이 마피아에게 살해당했습니다.
```

정보 손실은 없다. 사망은 실시간 이벤트로도 나간다. **잃는 것은 재미뿐이다.** 이때 조작권 아이템은 소모시키지 않는다.

### 조작본 (TC-15)

초코비가 R1 밤 `21:04:38`에 `NEWSPAPER_EDIT`을 썼다. 자기 이름이 든 문장을 지운다.

```
원본  곰돌이 님이 "그건 마피아가 제일 좋아하는 방식"이라 받아쳤고,
      초코비 님은 곧바로 "제일 수상하다"며 손가락을 들었다.

조작  곰돌이 님이 "그건 마피아가 제일 좋아하는 방식"이라 받아쳤고,
      회의장의 시선이 딸기우유 님에게 모였다.
```

**볼 포인트** — 사망자 줄·처형·역할은 조작본에 없어야 한다(밤에는 아직 존재하지 않는 줄이다). 조작이 통했는지는 R2 토론 `21:04:55`·`21:06:30`의 곰돌이 발화와 맞물린다.

## 4. 이렇게 나오면 실패다

```
✗  마지막까지 정체를 숨긴 초코비 님은 ...             ← 🔴 실제로 나왔다. 초코비는 마피아다
✗  가장 수상한 인물로 딸기우유 님이 떠올랐다          ← 신문이 판단했다
✗  회의를 방해하려는 의도가 읽힌다                    ← 의도를 추측했다
✗  딸기우유 님은 마피아였다                          ← 역할은 서버 템플릿만
✗  소금빵 님이 밤하늘 님에게 경고했다                 ← 주체 뒤집힘 (화자 ↔ 언급 대상)
✗  그는 끝까지 침묵했다                              ← 성별 추측
✗  (밤 로그 어절이 하나라도 등장)                     ← 절대 규칙 1. 코드가 잡는다
```

첫 줄이 [TC-12b](../scenario/scenario1/테스트-체크리스트.md)다. **밤 로그를 한 줄도 주지 않았는데 나왔다** — `AI 심판 지목 + 방어권 생존` 조합을 모델이 "정체를 숨긴 인물"로 엮는다. 입력이 깨끗해도 발생하므로 TC-12와 원인이 다르고, 프롬프트 규칙만으로는 안 걸러졌다. 함께 볼 표현: `진짜 마피아` · `베일` · `미궁` · `여전히 감춰진` · `그녀`·`그의`.

`"시간 낭비"라던 딸기우유 님, 하루 만에 최다 지목자로`는 **사실 요약이라 괜찮다.** 톤이 세지는 것과 판단하는 것은 다르다.
