# 프론트엔드 — STT 발화 수집 인수인계

화상 마피아 게임 **사건파일601**의 AI 기능 5종(조간신문 · AI 심판 · 진술대조권 · 키워드 뽑기 · 칭호 부여)은 **플레이어 발화 텍스트**를 입력으로 쓴다. 그 텍스트를 만드는 것이 프론트 몫이다.

**한 줄 요약 — 브라우저에서 Web Speech API 로 자기 마이크만 인식해서, 최종 결과 텍스트만 WebSocket 으로 보낸다.** 그 외에는 아무것도 붙이지 않는다.

## 2. 참고 구현 실행 — 5분

측정용으로 만든 페이지지만 **Web Speech API 부분은 실서비스에 그대로 쓸 수 있다.**

1. VS Code 에서 이 폴더를 열고 확장 **Live Server** 를 설치한다
2. [stt-test/index.html](stt-test/index.html) 우클릭 → **Open with Live Server**
3. Chrome 이 열리면 마이크 권한을 허용하고 **시작** 을 누른다
4. 페이지에 있는 대본을 소리내어 읽는다

> ⚠️ **`file://` 로 열면 마이크가 열리지 않는다.** `localhost` 또는 https 여야 한다.
> ⚠️ **Chrome / Edge 만 된다.** Firefox 는 `SpeechRecognition` 미지원이고, 팀은 Chrome 고정으로 간다.
> ⚠️ 인식은 온디바이스가 아니다 — **오디오가 구글 서버로 전송된다.** 인터넷이 필요하고 개인정보 고지 대상이다.

### 읽어볼 곳

`index.html` 의 `<script>` 안에서 이 네 군데면 된다.

| 함수 | 볼 것 |
|---|---|
| `createRecognition()` | 필수 설정 3줄 — `lang='ko-KR'` · `continuous=true` · `interimResults=true` |
| `onresult` | **`event.resultIndex` 부터 순회한다.** 처음부터 돌면 같은 발화를 중복 전송한다 |
| `onend` | **300ms 뒤 재시작.** Chrome 은 조용하면 알아서 종료하므로, 안 켜주면 게임 중에 조용히 죽는다 |
| `onerror` | `not-allowed`(권한 거부)와 `no-speech`(흔함)를 구분해서 다룬다 |

### 직접 말해보면 알게 되는 것

대본을 읽으면 **이런 오인식이 실제로 나온다.** 실측 결과다.

```
방어권 있습니다   →  방학과 있습니다      (방어권 주장이 사라진다)
찬성했습니다      →  편성했습니다         (정상 한국어라 교정 불가)
시간 낭비        →  시간 남비
딸기우유         →  강혜린 / 강예은      (한 줄 안에서도 갈린다)
```

**이걸 프론트가 고칠 필요는 없다.** AI 파트가 이 상태를 전제로 프롬프트를 설계해뒀다. 다만 "왜 인식이 이렇게 나오냐"는 문의가 오면 STT 한계라는 것만 알고 있으면 된다.

## 3. 실서비스에서 바꿔야 하는 것 — 4개

측정 페이지와 다른 점이다. 상세는 [STT-인수인계.md §1-2](STT-인수인계.md).

| 측정 페이지 | 실서비스 |
|---|---|
| final 결과를 화면 표에 쌓는다 | **WS `speech.utterance` 로 서버에 보낸다** |
| 사람이 시작·정지 버튼을 누른다 | **phase 전환에 맞춰 자동으로.** 밤에는 시민 마이크를 끈다 |
| 자동 재시작이 체크박스다 | **항상 켠다** |
| `confidence` 를 표에 찍고 0.8 미만을 강조한다 | **`confidence` 를 아예 쓰지 않는다.** 아래 |

### 🔴 `confidence` 로 필터링하지 말 것

실측에서 **틀린 것은 자신 있게 오고 맞은 것이 낮게 왔다.** 0.8 미만은 짧은 대꾸 하나와 정확히 맞은 문장 하나뿐이었고, 위험한 오인식은 **전부 0.8 이상**이었다. 필터를 걸면 맞은 발화만 사라진다.

### 🔴 페이로드에 이것들을 넣지 말 것

`playerId` · `roomId` · `phase` · `round` — **전부 서버가 세션과 게임 상태에서 유도한다.** 클라이언트가 `phase` 를 지정할 수 있으면 **밤 발화를 낮 발화로 위장해 공개 로그에 심을 수 있다.** 보내는 것은 텍스트와 시각뿐이다.

```jsonc
// WS  speech.utterance   (fire-and-forget, 응답 없음)
{ "text": "저는 어제 밤에 아무것도 안 했어요",
  "startedAt": 1721980000123, "endedAt": 1721980002456 }
```

## 4. 완료 기준

- [ ] Chrome 에서 3분 토론 동안 인식이 끊기지 않는다 (`onend` 재시작 동작)
- [ ] final 결과만 전송된다 (interim 이 서버에 도착하지 않는다)
- [ ] 페이로드에 `playerId` · `phase` · `round` 가 없다
- [ ] 밤에 시민 클라이언트의 인식기가 정지한다
- [ ] 마이크 권한 거부 시 사용자에게 안내가 나간다

---

## 5. 정해야 할 것 — 회의 안건

| 항목 | 정하는 쪽 |
|---|---|
| **밤에 시민 마이크를 누가 막나** — 프론트가 인식기를 끄는지, 서버가 버리는지 (**둘 다 권장**) | 프론트 + 백엔드 |
| 헤드셋 권장 안내를 어디에 띄울지 — **스피커로 나온 남의 목소리가 내 마이크에 들어가면 그 말이 내 발화로 저장된다.** 하지 않은 말로 모순 판정을 받는다 | 프론트 + 기획 |
| 인식 중(interim) 텍스트를 화면에 보여줄지 | 프론트 |
| 닉네임 제약 — STT 는 사전에 없는 닉네임을 못 맞춘다. 한글·길이 제한을 걸지 | 기획 |

전체 미결 목록은 [STT-인수인계.md §4](STT-인수인계.md).
