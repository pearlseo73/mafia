## 1. 팀 확정 스택 (2026-07-27 수령)

| 영역 | 버전·기술 |
|---|---|
| 런타임 | **Java 25** |
| 프레임워크 | **Spring Boot 4.x** |
| LLM | **Spring AI 2.0.0** (GMS 경유) |
| 빌드 | **Gradle** — Groovy DSL (`build.gradle`, `.kts` 아님) |
| DB | **MySQL** + **JPA** + **QueryDSL** |
| 캐시·실시간 상태 | **Redis** |

프론트엔드는 Vue + `@vladmandic/face-api`, STT는 브라우저 Web Speech API(Chrome/Edge 전용)다. 자세한 배경은 [README.md](../README.md).

### AI 파트는 JPA·QueryDSL을 거의 쓰지 않는다

발화 로그는 Redis(`utt:{roomId}:public`)에 있고, MySQL에는 집계 결과만 저장한다([AI기능-구현설계 §2-4](AI기능-구현설계.md)). QueryDSL 러닝커브가 AI 작업을 막지 않는다.

## 2. 버전 호환

### Spring AI ↔ Spring Boot

| Spring AI | 지원 Spring Boot |
|---|---|
| **2.0.0** | **4.0.x · 4.1.x** ← 우리 |
| 1.1.8 | 3.4.x · 3.5.x |
| 1.0.9 | 3.3~3.4 |

Spring Boot 4.1 기준 Java는 **최소 17, 최대 26**. Gradle은 **8.14 이상 또는 9.x**, Maven은 3.6.3 이상.

### Boot 4 = Jackson 3

패키지가 `com.fasterxml.jackson` → **`tools.jackson`**으로 바뀌었다. Jackson 2 기준 코드는 그대로 컴파일되지 않는다. `report/`(이전 프로젝트 참고 코드)가 여기에 해당한다.

### Java 바이트코드는 하위 호환되지 않는다

```
Java 25로 컴파일 → Java 21 JVM 실행   ❌ UnsupportedClassVersionError
Java 21로 컴파일 → Java 25 JVM 실행   ✅
```

팀·배포 서버와 **같은 버전**을 쓴다. 확신이 없으면 낮은 쪽에 맞춘다.

## 3. 한글 인코딩 — 반드시 먼저 잡을 것

이 리포는 **파일명과 내용이 전부 한글**이다(`발화로그-공개.txt`, `기능명세서.md`). Windows에서 JDK 기본 인코딩이 UTF-8이 아닐 수 있어, 명시하지 않으면 **발화가 깨진 채로 프롬프트에 들어간다.** 프롬프트가 아무리 좋아도 입력이 깨지면 무슨 일이 일어나는지 알 수 없게 된다.

- `build.gradle`에 컴파일 인코딩 UTF-8 지정
- 파일 읽을 때 `StandardCharsets.UTF_8` 명시
- IntelliJ `Settings > Editor > File Encodings` — Global · Project · Properties Files 전부 UTF-8

## 4. Gradle (Maven만 써봤다면)

### 명령 대응

| Maven | Gradle |
|---|---|
| `mvn clean` | `./gradlew clean` |
| `mvn test` | `./gradlew test` |
| `mvn package` | `./gradlew build` |
| `mvn spring-boot:run` | `./gradlew bootRun` |
| `mvn dependency:tree` | `./gradlew dependencies` |
| `mvn test -Dtest=FooTest` | `./gradlew test --tests "*FooTest*"` |
| `mvn package -DskipTests` | `./gradlew build -x test` |

### 의존성 스코프 이름

| Maven `<scope>` | Gradle |
|---|---|
| `compile` | `implementation` |
| `provided` | `compileOnly` |
| `runtime` | `runtimeOnly` |
| `test` | `testImplementation` |
| `import` (BOM) | `platform(...)` |

### Gradle Wrapper

`gradlew`, `gradlew.bat`, `gradle/wrapper/`는 **git에 커밋한다.** 로컬에 Gradle을 설치하지 않아도 되고, 팀 전원이 같은 Gradle 버전으로 빌드한다. 의존성 좌표는 기억으로 적지 말고 [start.spring.io](https://start.spring.io)에서 생성해 가져온다.

## 5. IDE

**IntelliJ IDEA Ultimate** (학생 인증). 이전에 쓰던 STS도 병행 가능 — Gradle 프로젝트는 IDE와 무관하고, 팀에 공유되는 건 빌드 파일이지 IDE 설정이 아니다.

- `.gitignore`에 **양쪽 메타파일**을 넣는다 — `.idea/`, `.settings/`, `.classpath`, `.project`, `bin/`
- JDK는 따로 설치하지 말고 `Project Structure > SDKs > Download JDK`로 받는다
- 첫 실행 후 Windows Defender 예외 추가 알림을 수락하면 인덱싱 체감 속도가 크게 개선된다
- Ultimate의 **HTTP Client**로 GMS 엔드포인트를 바로 검증할 수 있다

### STS로 작업할 때 차이

- 임포트: `File > Import > Existing Gradle Project`
- 의존성 갱신: 프로젝트 우클릭 → `Gradle > Refresh Gradle Project` (Maven의 `Update Project`에 대응). **이걸 안 하면 새 의존성이 IDE에 안 보인다**

## 6. 이 리포와 팀 레포의 관계

| | 어디 |
|---|---|
| 설계 문서 · 로그 픽스처 · 기대답안 | **이 리포** |
| **프롬프트 검증 (지금)** | **이 리포의 `ai-lab/`** |
| 실서비스 Spring AI 구현 | **팀 백엔드 레포** (나중에 옮긴다) |

### `ai-lab/` — 프롬프트 검증용 실험실

**당초에는 팀 레포를 기다렸다가 그 안에서 하려 했으나, 백엔드 팀 작업이 길어져 먼저 시작하기로 바꿨다** (2026-07-27).

리포 안에 두는 이유는 하나다 — **프롬프트·기대답안·테스트가 한 커밋에서 같이 바뀐다.** 별 리포로 쪼개면 "프롬프트는 고쳤는데 기대답안은 옛 버전" 상태가 반드시 생긴다. 픽스처도 `../log_analysis/scenario/scenario1/...`로 바로 읽을 수 있다(Gradle 테스트의 작업 디렉터리가 프로젝트 폴더다).

```
mafia-ai/
├─ docs/  log_analysis/          기존
└─ ai-lab/                        ← Spring Boot (Gradle)
   ├─ build.gradle
   └─ src/
      ├─ main/resources/prompts/  진술대조.md → statement-compare.st
      └─ test/java/...            하네스 테스트
```

**의존성은 Spring AI OpenAI 스타터 하나만 넣는다.** Web·JPA·MySQL·Redis를 붙이면 프롬프트 한 줄 고칠 때마다 인프라를 띄워야 하고, QueryDSL 애노테이션 프로세서 설정(Boot 4 + Java 25에서 특히 손이 간다)도 불필요하게 끌어온다.

`build.gradle`에 **한글 인코딩을 반드시 추가한다** (§3 참조).

```gradle
tasks.withType(JavaCompile).configureEach { options.encoding = 'UTF-8' }
tasks.withType(Test).configureEach { systemProperty 'file.encoding', 'UTF-8' }
```

### 팀 레포로 옮길 때

**`ai-lab`은 버려도 되는 실험실이고 정본이 아니다.** 팀 레포를 받으면 프롬프트 `.st`와 검증 코드를 옮기고, 그때부터 **프롬프트 정본은 팀 레포의 `src/main/resources/prompts/*.st`**다. 사본을 양쪽에 두면 반드시 갈라진다.

옮긴 뒤에는 `@SpringBootTest`로 전체 컨텍스트를 올리면 MySQL·Redis에 붙으려다 실패하므로 범위를 좁혀야 한다. `ai-lab`에서는 DB 의존성이 없어 그럴 필요가 없다.
