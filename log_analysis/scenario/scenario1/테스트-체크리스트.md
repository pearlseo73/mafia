# 로그 분석 테스트 체크리스트

> 최종 수정: 2026-07-26
> 대상 픽스처: [발화로그-공개.txt](발화로그-공개.txt) · [발화로그-밤마피아.txt](발화로그-밤마피아.txt) · [게임이벤트.txt](게임이벤트.txt)
> 시나리오 설정: [시나리오-설정.md](시나리오-설정.md)

픽스처에 **의도적으로 심어둔 테스트 케이스**와 검증 기준이다.
`실패 조건`이 명시된 항목은 그 동작이 나오면 프롬프트를 고쳐야 한다.

---

## 1. 진술대조권 (`STATEMENT_COMPARE`)

- [ ] **TC-1. 박도현 3단 모순 검출** ← 핵심 케이스

  | 라운드 | 시각 | 발언 |
  |---|---|---|
  | R1 | 21:01:12 | "강예린 씨가 **제일 수상해요**" |
  | R2 | 21:06:20 | "저는 **처음부터 강예린 씨를 믿었습니다**" |
  | R3 | 21:10:45 | "강예린 씨를 **의심한 적이 없습니다**" |

  세 발언이 서로 충돌한다는 것을 검출해야 한다. 인용은 **실제 로그의 문장이어야 한다.**

- [ ] **TC-2. 같은 라운드 내 자기모순** — R3 `21:10:23` "강예린 씨를 처형하는 데 **찬성했습니다**" ↔ `21:10:45` "**의심한 적이 없습니다**"

- [ ] **TC-3. 말과 행동 불일치** — R1 `21:01:12` "강예린 씨한테 넣을 생각입니다" ↔ 실제 투표 `박도현→최지우`([게임이벤트.txt](게임이벤트.txt) 21:03:36)

  > **미결:** 진술대조권이 발화만 보는지, 투표 내역까지 대조하는지 결정 필요. 발화 로그만으로는 검출 불가능하다.

- [ ] **TC-4. 발화 부족 폴백** — 최지우는 게임 내내 2마디(`21:01:45`, `21:02:50`)만 한다
  - 기대: "분석할 발언이 부족합니다" (`hasFindings: false`, HTTP 200)
  - **실패 조건: 억지 모순을 만들어낸다** ← 가장 위험한 실패 모드
  - LLM 호출 자체를 생략하는 임계값이 동작하는지도 함께 확인

- [ ] **TC-5. 모순 없음 정상 출력** — 김서준은 일관된 추리만 한다
  - 기대: "모순이 발견되지 않았습니다"
  - **실패 조건:** 없는 모순을 지적하거나 에러로 처리

- [ ] **TC-6. 1라운드 사용 시** — 대조할 이전 발화가 없는 상황 처리

- [ ] **TC-7. 사망자 지목 차단** — 최지우(R1 밤 사망)를 R2 이후 지목 → `TARGET_NOT_ALIVE`

---

## 2. 키워드 뽑기 (`KEYWORD_EXTRACT`)

- [ ] **TC-8. 강예린 키워드 추출** (R1) — 실제 발화에 있는 표현이 나와야 한다
  - 근거 발화: `21:00:15` "시간 낭비", `21:00:31` "느낌으로", `21:01:38` "억울하면", `21:02:58` "근거도 없이"
  - **실패 조건:** 로그에 없는 단어를 생성

- [ ] **TC-9. 최지우 대상** — TC-4와 동일하게 발화 부족 응답

- [ ] **TC-10. 로그 범위가 현재 라운드로 제한되는지** — R2에서 사용 시 R1 발화가 섞이면 안 된다 (진술대조권과의 차별점)

---

## 3. 조간신문

- [ ] **TC-11. R2 신문 생성** — R1 낮 토론 로그 기반 + 최지우 사망 고정 템플릿
- [ ] **TC-12. 밤 로그 유출 검사** ← **최우선 회귀 테스트**
  - [발화로그-밤마피아.txt](발화로그-밤마피아.txt)의 문구(예: "그래야 안 걸려요", "최지우로 하죠")가 신문에 등장하면 **즉시 실패**
  - 이 한 줄이 새면 마피아 신원이 그대로 노출된다
- [ ] **TC-13. 1000자 제한** (명세 17-2) — 프롬프트 지시 + 서버 truncate 이중 적용
- [ ] **TC-14. R1 낮 시작에는 신문 없음** — 첫 낮에는 이전 밤이 없다
- [ ] **TC-15. 조작권 반영** — 박도현이 R1 밤에 `NEWSPAPER_EDIT` 사용(`21:04:38`). R2 낮 신문은 조작된 버전이어야 하고, 정민재가 이를 알아채는 발화(`21:04:55` "신문 내용이 좀 이상한데요")와 맞물린다

---

## 4. AI 심판

- [ ] **TC-16. 발동 조건** — R1 투표가 3자 동률(박도현2·김서준2·최지우2)로 최다득표자 미특정 → 심판 진행
- [ ] **TC-17. 대상 생존 검증** — LLM이 사망자·미존재 ID를 반환하면 서버가 걸러내는지
- [ ] **TC-18. 출력 순서** — 사유 나열 후 마지막에 대상 발표 (명세 20-5). 순서가 뒤집히면 연출이 깨진다
- [ ] **TC-19. 방어권 발동** — 대상 박도현이 `BOMB_DEFENSE` 보유 → 처형 없음 + 우측에 방어권 안내 (명세 20-6)
- [ ] **TC-20. LLM 실패 폴백** — 타임아웃 시 규칙 기반 대체 (T11 미확정)
- [ ] **TC-21. 역할 정보 차단** ← 중요
  - AI는 누가 마피아인지 모른 채 **발화만으로** 판단해야 한다
  - **실패 조건:** 프롬프트에 역할이 새어 들어가 정확히 마피아만 고른다. 정답률이 비정상적으로 높으면 유출을 의심할 것

---

## 5. 칭호 부여

- [ ] **TC-22. 팀킬 검출** — 박도현(마피아)이 R2에서 동료 강예린에게 투표(`21:08:31`)하고 최후변론에서 찬성(`21:09:04`) → 처형
  - 기대: "최고의 팀킬상" 계열
- [ ] **TC-23. 오판 검출** — 이하윤은 두 번 다 시민에게 투표(R1 김서준, R2 정민재)하고, 최후변론에서 마피아 강예린을 살리려 반대표
- [ ] **TC-24. 침묵 검출** — 최지우 발화 2건, 아이템 0개
- [ ] **TC-25. 1인 1칭호 · 중복 없음** — 한 번의 호출로 전원 배정, 서버가 검증
- [ ] **TC-26. 사실관계 환각 금지** ← 하이브리드 설계의 검증 지점
  - **실패 조건:** 팀킬하지 않은 김서준·정민재에게 팀킬 칭호를 준다
  - 서버 집계 지표를 넣지 않고 발화만 줬을 때와 결과를 비교해볼 것
- [ ] **TC-27. 밤 로그 opt-in 효과 비교** — 밤 로그를 넣은 프롬프트와 안 넣은 프롬프트의 칭호 품질 차이
  - 근거 발화: `21:04:20` "그래야 안 걸려요", `21:09:25` "이하윤은 계속 엉뚱한 사람만 찍으니까"
  - 차이가 없으면 밤 로그를 프롬프트에서 제거한다

## 6. 로그 격리 회귀 테스트

- [ ] **TC-28.** `getPublicUtterances()`가 밤 로그를 절대 반환하지 않는지 (단위 테스트)
- [ ] **TC-29.** 낮 기능 4종의 출력에서 밤 로그 문구를 문자열 검색 — 하나라도 걸리면 실패
- [ ] **TC-30.** 아이템 분석 결과가 요청자 외 다른 플레이어에게 전송되지 않는지 (T6 확정 사항)

## 7. 픽스처 보강 필요 — 현재 커버되지 않는 케이스

아래는 **현재 픽스처에 없어서 테스트할 수 없는** 항목이다.

| 미커버 케이스 | 관련 명세 | 필요한 이유 |
|---|---|---|
| **없는 아이템을 있다고 거짓 주장** | 진술대조 | 현재 아이템 언급 5건이 전부 사실이다(§8 참조) |
| **아무도 죽지 않은 밤** | 17-7 "평화로운 밤입니다" | R1·R2 밤 모두 사망자가 있어 무사망 분기를 못 탄다 |
| **AI 위임 버튼 사용** | 18-7 | 현재 6명 전원이 특정인에게 투표한다 |
| **스킵 버튼 사용** | 14-3, 14-4 | 토론 시간 차감·조기 투표 전환 로그가 없다 |
| **조작 전/후 신문 텍스트 대조** | 17-4, 17-5 | 조작권 사용 기록만 있고 원본·수정본이 없다 |
| **마피아가 시민을 지목하지 않은 밤** | 21-5 | "마피아가 아무도 선택하지 않으면 시민은 죽지 않는다" 분기 |

## 8. 참고: 아이템 거짓 주장은 현재 없다

픽스처의 아이템 언급 5건은 **모두 실제 보유·사용과 일치한다.**

| 시각 | 발언자 | 발언 | 실제 보유 |
|---|---|---|---|
| 21:02:09 | 정민재 | "아이템 쓸게요 키워드 뽑아볼게요" | `KEYWORD_EXTRACT` ✅ |
| 21:03:10 | 이하윤 | "아이템 써서 두 표로 넣을게요" | `VOTE_DOUBLE` ✅ |
| 21:04:08 | 박도현 | "저 방어권 있습니다" | `BOMB_DEFENSE` ✅ |
| 21:06:38 | 강예린 | "아이템 쓸게요" | `SILENCE` ✅ |
| 21:11:05 | 김서준 | "아이템 쓸게요 진술 대조해볼게요" | `STATEMENT_COMPARE` ✅ |

**추가 제안:** 박도현이 R3 토론에서 "저도 진술대조권 있는데 써볼까요" 같은 허위 주장을 하게 만들면, 발화와 [게임이벤트.txt](게임이벤트.txt)의 `ITEM_GRANT`를 대조하는 테스트 케이스가 생긴다. 진술대조권 프롬프트가 아이템 보유 정보까지 받을지는 별도 결정 사항이다.
