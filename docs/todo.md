## GMS 검증에서 나온 것 (2026-07-27)

### 🔴 가장 중요한 발견 — 핵심 케이스가 기본 프롬프트로는 실패한다

TC-1의 세 발언을 라운드 표시 없이 그냥 주고 "모순인가" 물었더니 `gpt-5.4-mini`가 이렇게 답했다.

> "모순은 아니며, u2와 u3는 강예린을 믿거나 의심하지 않았다고 말할 뿐이고 u1은 강예린이 수상하다고 말해 서로 직접 충돌하지 않습니다."

**"모순이 아니다"로 판정했다.** [테스트-체크리스트](../log_analysis/scenario/scenario1/테스트-체크리스트.md)의 TC-1이 그냥은 통과하지 않는다는 뜻이다.

원인 추정 두 가지 — ① **라운드 정보를 안 줬다**(u2·u3가 *과거에 대한 주장*임을 알 수 없다) ② [진술대조 프롬프트](../log_analysis/prompts/진술대조.md)의 **System 규칙 4**("생각이 바뀔 수 있는 의견 변화와 과거를 다르게 진술하는 것은 다르다")가 빠져 있었다.

→ 프롬프트에서 **라운드 표시가 장식이 아니라 판정의 필수 입력**이라는 게 확인됐다. 실제 프롬프트로 다시 돌려봐야 한다.

### 확정된 것

- **AI 심판 모델 = `gpt-5.4-mini`** — reasoning 모델의 "스트리밍 초반 침묵" 우려가 실측에서 나타나지 않았다(첫 글자 1.13초). 트레이드오프가 존재하지 않아 판정 품질을 택한다
- **`gpt-5.x`는 `max_tokens`를 쓰면 400** — `max_completion_tokens` 필수. 모델을 바꾸면 파라미터 이름도 바꿔야 한다
- **`GET /models` 미지원** — 모델명을 API로 발견할 수 없다

### 남은 미결

- **`temperature`가 실제로 반영되는지** — `gpt-5.4-mini`에 넣어도 400이 아니지만(강사님 주석과 다름) 무시될 수 있다. 칭호·신문의 다양성이 실제로 달라지는지 비교 필요
- **기능별 토큰 상한 값** — 전역값 하나로는 조간신문과 키워드 뽑기를 동시에 만족시킬 수 없다
- **GMS `response_format`(json_schema) 지원 여부** — 지원하면 프롬프트 대신 API 레벨로 출력 형식을 강제할 수 있다
