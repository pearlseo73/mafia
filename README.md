# 🎭 화상 마피아 (Video Mafia)

웹 브라우저에서 즐기는 **화상 기반 마피아 게임**. 실시간 화상/음성 대화에 **AI 기능**을 결합해
몰입감과 재미를 더한 프로젝트입니다.

---

## ✨ 주요 기능

### 게임
- WebRTC 기반 실시간 화상/음성 통화
- 마피아 게임 진행 로직 (낮 토론 / 투표 / 밤 / 최후 변론)

### AI 기능
1. **음성 로그 분석 (STT + LLM)**
   - 사용자 대화를 STT로 텍스트화하여 게임 로그로 저장
   - 📰 **조간신문**: 매일 아침 밤사이 사건과 토론을 요약한 기사 자동 발행
   - ⚖️ **AI 심판**: 발언의 모순·회피·투표 패턴을 분석해 마피아 의심도 추정
   - 🔍 **진술 분석 아이템**: 특정 사용자를 지목해 그 사람의 발언을 집중 분석

2. **얼굴/표정 분석 (MediaPipe 등)**
   - 최후 변론 시 최다 득표자의 얼굴을 확대
   - 표정(blendshape) 기반 감정 분석 및 **"AI 동요 지수"**(연출용) 표시
   - (실험) rPPG 심박 추정으로 긴장 연출

> ⚠️ 표정·심박 기반 지표는 **오락용 연출**이며, 과학적 거짓말 탐지가 아닙니다.

## 🏗️ 아키텍처

```
┌─────────────┐   WebRTC    ┌──────────────────────┐
│    Vue      │◄───화상────►│   참가자 브라우저      │
│ (프론트엔드) │             │  MediaPipe JS (실시간) │
└──────┬──────┘             └──────────────────────┘
       │ REST / WebSocket
┌──────▼──────────┐   REST / gRPC   ┌────────────────────────┐
│  Spring Boot    │◄───────────────►│   FastAPI (Python)     │
│ (게임 로직·세션) │                 │  - STT (faster-whisper)│
│                 │                 │  - LLM 로그 분석        │
└─────────────────┘                 │  - 표정/감정/심박 분석  │
                                    └────────────────────────┘
```

- **프론트엔드**: Vue — 실시간 얼굴 랜드마크는 브라우저 MediaPipe JS로 처리(서버 부하↓)
- **백엔드**: Java Spring Boot — 게임 로직·세션·투표·상태 관리
- **AI 서비스**: Python FastAPI — STT / LLM / CV 기능 (Python ML 생태계 활용)
