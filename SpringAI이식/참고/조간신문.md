| 득표 수치·생존자 목록·발화 번호 | **넣지 않는다** | 평문 출력이라 번호를 되받을 계약이 없다. 득표는 §9 미결 1 |

**`DAY_START`와 `RESULT`를 뺀 이유가 서로 다르다.** `DAY_START`는 어제 신문에 대한 반응("근데 신문 내용이 좀 이상한데요")이라 신문이 자기 얘기를 인용하게 된다. `RESULT`는 처형 반응이라 사망자 줄과 겹치고, 생성 창을 3초 더 깎는다.

**컷오프를 코드로 하는 이유는 진술대조와 같다** — "몇 시까지"를 프롬프트에 글로 적으면 모델이 안 지킨다. 여기에 `assert phase != NIGHT`를 한 겹 더 둔다(§7).

## 2. 형태 — D안 타블로이드

### 골격

```
【601 조간】 제N호                        ← 서버

■ [사망자 — 서버, 아침에만]
■ [어제의 최대 사건 한 줄 — LLM]

[본문 2문단. 첫 문단은 극적인 장면 2~3개, 둘째 문단은 실제 결과 — LLM]
```

**헤드라인 두 줄만 읽어도 성립해야 한다.** 낮 시작에 10초만 표시하고 닫기 때문이다(17-6).

### 밤 열람본 (제1호 · 조작권 소지자에게)

```
【601 조간】 제1호

■ "시간 낭비"라던 딸기우유 님, 하루 만에 최다 지목자로

"느낌으로 가야죠" — 딸기우유 님의 한마디에 회의장이 얼어붙었다. 곰돌이 님이
"그건 마피아가 제일 좋아하는 방식"이라 받아쳤고, 초코비 님은 곧바로 "제일
수상하다"며 손가락을 들었다.

밤하늘 님은 라면왕 님의 매끄러운 진행을 의심했고, 말 없던 소금빵 님도 그 시선을
피하지 못했다.

투표함이 열렸으나 표가 갈렸다. AI 심판이 부른 이름은 초코비 님 — 그러나 폭탄은
터지지 않았다.
```

```
"그건 마피아가 제일 좋아하는 방식"이라 받아쳤고, 회의장의 시선이 딸기우유 님에게
모였다.
```

초코비가 자기 이름이 든 문장을 지운 것이 조작이다(§8).

### 폐기한 후보 — 왜 D를 골랐는지

| 안 | 형태 | 문제 |
|---|---|---|
| A | 신문 기사체(담담) | 사건 요약 느낌. 재미가 없다 |
| B | 항목 나열 | 258자로 가장 빨리 읽히지만 신문 느낌이 없다 |
| C | 헤드라인 + 본문 | A와 B의 절충. 여전히 담담하다 |
| E | 논평이 붙는 신문 | 재미있지만 **논평이 판단으로 넘어갈 위험**이 있다 |
| F | 어록 코너 | 가장 신문답고 재미있으나 **발언 인용 4개가 아이템 2종을 잡아먹는다** |

F를 버린 이유가 중요하다. 신문이 아침마다 어록을 공짜로 주면 **진술대조권과 키워드 뽑기를 왜 쓰는가**가 된다. 인용 상한을 1~3개로 둔 것이 이 때문인데, **3개를 다 쓰면 실제로 진술대조 증거가 새어나간다** (§8, §9 미결 2).

## 3. 사망자 템플릿 — 세 경우

**게임이벤트.txt**에 **처형과 밤 살해가 다르게 기록돼 있다.**

```
[21:09:10] DEATH 딸기우유 cause=EXECUTION role=마피아     ← 역할이 붙는다
[21:09:43] DEATH 밤하늘 cause=NIGHT_KILL                ← 역할이 없다
```

→ **처형만 역할이 공개된다.**

| 경우 | 템플릿 |
|---|---|
| 밤 살해 | `■ {닉네임} 님이 마피아에게 살해당했습니다.` |
| 처형 | `■ {닉네임} 님 처형 — {역할}였다` |
| 아무도 안 죽음 | `■ 평화로운 밤이었습니다` (17-7, 문구 미확정) |

제2호처럼 처형과 밤 살해가 겹치면 두 줄 다 나가고, **밤 살해 줄이 위에 온다** — 아침에 새로 알게 되는 사실이 그쪽이다.

**역할은 반드시 서버가 넣는다.** LLM에게 "딸기우유가 마피아였다"를 주면 절대 규칙 2를 어기는 것이고, 본문에서 그 정보로 다른 사람을 추측할 위험이 생긴다.

## 4. 2단 조립 — 조작을 구조로 막는다

`write_newspaper()`가 돌려주는 `body`가 **밤에 조작권 소지자에게 보여주는 것 그대로**다. 아침에 서버가 `masthead()` + `casualty_lines()`를 앞에 붙인다.

```
밤    [머리글 — 서버]  +  [본문 — LLM]                      ← 조작 대상
아침  [머리글]  +  [사망자 줄 — 서버]  +  [본문(조작 반영)]
```

따라오는 것:

- **밤에는 사망자 줄을 만들 수 없다.** 밤 살해가 아직 일어나지 않았다. 이 순서 덕에 **처형·역할 공개 관련 조작이 구조적으로 무효화**된다 — 조작권이 닿는 것은 토론 요약뿐이다
- **사망자 줄은 LLM 출력과 문장이 이어지면 안 된다.** 요약이 없어도 홀로 성립해야 한다. `■` 두 줄이 독립적이라 이 조건을 만족한다
- **사전 열람은 조작권 소지자 한 명만이다.** 마피아 전원에게 주면 시민이 상시 불리해진다
- **폴백(LLM 실패)이면 조작권 아이템을 소모시키지 않는다.** 고칠 본문이 없다

### 폴백 — 사망자 줄이 남는 이유

`17-7`의 고정 템플릿은 정확성 장치가 아니라 **LLM 호출이 실패했을 때의 폴백**이다.

```
【601 조간】 제1호

■ 소금빵 님이 마피아에게 살해당했습니다.
```

이것만 나가도 **정보 손실은 없다** — 사망은 어차피 실시간 이벤트로도 나간다. 잃는 것은 재미뿐이다. 그래서 **타임아웃을 짧게 잡을 수 있다.**

### 생성 창 — 재시도 예산을 여기서 정한다

명세 17-1은 **낮 투표 시작**이다. R1에 대입하면 `21:03:06`인데, **어젯밤의 큰 사건 셋이 그 뒤에 일어난다.**

```
21:03:06  R1/DAY_VOTE 시작       ← 17-1대로면 여기서 생성 (동률·심판·사망이 안 담긴다)
21:03:36  투표 3자 동률
21:04:08  AI 심판 → 초코비 지목 → 방어권 발동
21:04:09  결과 확정              ← 현재 설계: 여기서 생성
21:04:12  밤 시작
21:04:17  조작권 소지자에게 노출 (+5초)
21:04:42  소금빵 사망
21:04:45  제1호 전원 공개
```

**생성 창이 R1은 4초, R2는 9초뿐이다.** [§6](AI기능-구현설계.md)에 적힌 "60초 이상"은 17-1 기준이었고, 결과 확정 뒤로 늦추면서 창이 이만큼 줄었다. 노출을 밤 시작 +5초로 둬서 R1이 9초가 된다.

→ **워밍업 호출이 필수다.** 첫 호출만 4~7초가 걸린다(진술대조 실측). 방 생성 시점에 한 번 태워둬야 R1 신문이 폴백으로 떨어지지 않는다.

## 5. 렌더 — 이름이 둘이면 주체가 뒤집힌다

```
[21:02:00] 토론 · 말한사람 밤하늘 · 발언 소금빵 씨는 계속 조용한데 이것도 전략일 수 있어요
결과: 처형 없음 (방어권_발동)
```

**한 줄에 이름이 둘(화자 + 언급 대상) 있으면 모델이 주체를 뒤집는다.** 07-30 실측 — `21:02:00`이 2회 연속 "소금빵이 경고했다"로 나왔는데, 실제로는 밤하늘이 소금빵을 지적한 말이다. `말한사람` · `발언` 라벨로 끊어서 고쳤다.

발언을 따옴표로 감싸지 않는다. 본문 인용 상한과 충돌해서 모델이 입력의 따옴표를 인용 허가로 읽는다.

## 6. 프롬프트 (SYSTEM 2396자 · USER 60자)

진술대조의 규칙 3개와 달리 **길다.** 창작이라 문체·구성 지시가 대부분을 차지하고, 형식 예시 3개가 들어 있다. 판정이 아니라 톤을 잡는 지시라 축약의 이득이 크지 않았다.

### 지킬 것 — 4개

| 규칙 | 왜 |
|---|---|
| **누가 마피아인지 판단하지 않는다.** 누가 누구를 의심했는지만 쓴다 | 딸기우유는 실제 마피아다. 신문이 판단하면 시민에게 정답을 준다 |
| AI 심판 결과·방어권 발동을 **인물 평가와 연결하지 않는다** | 방어권은 아이템 보유의 결과이고 역할과 무관하다 |
| 주어진 발언 밖의 사실을 쓰지 않는다 | 환각 방어 |
| 성별을 추측하지 않는다 | 닉네임만 받는다 |

인용은 1~3개, 인용 직후에는 **반응이나 분위기 변화를 반드시 붙인다** — 어록 나열이 되면 아이템 2종이 시들해진다.

### 실패 예시로 기대답안에 넣을 것

```
✗  가장 수상한 인물로 딸기우유 님이 떠올랐다
✗  회의를 방해하려는 의도가 읽힌다
```

톤이 세지는 것과 판단하는 것은 다르다. `"시간 낭비"라던 딸기우유 님, 하루 만에 최다 지목자로`는 사실 요약이라 괜찮다.

### 서버가 하는 것

사망자 줄 삽입 · 머리글·호수 · 500자 검사 · **밤 로그 유출 검사**(TC-12) · `max_tokens` 상한.

## 7. 방어 — 두 겹

| 층 | 무엇 | 왜 |
|---|---|---|
| 입력 | `phase` 화이트리스트 4종 + `assert phase != NIGHT` | 절대 규칙 1을 부탁이 아니라 입력에서 막는다. 문자열 검사보다 정확하다 |
| 입출력 | **밤 전용 어절 검사** — 밤 로그 어절 중 낮에 없는 4자 이상만 ([TC-12](테스트-체크리스트.md)) | 눈으로는 놓치고, 한 줄만 새면 마피아 신원이 그대로 노출된다 |
| 출력 | 500자 초과 검사 (17-2) | `max_tokens`로 이미 막히지만 폴백 조립 뒤 길이를 다시 본다. 지금은 경고만 하고 truncate는 서버 몫으로 남겨뒀다 |
| 출력 | **역할 추정 표현 검사 ([TC-12b](테스트-체크리스트.md)) — 미구현** | 아래 |

### 🔴 TC-12b — 입력이 깨끗해도 정체를 암시한다

07-30 실측. 밤 로그를 한 줄도 주지 않았는데 제1호 본문이 이렇게 나왔다.

```
마지막까지 정체를 숨긴 초코비는 ...
```

**초코비는 실제 마피아다.** 원인은 입력의 `AI 심판 지목 + 방어권으로 생존` 조합이고, 모델이 이걸 서사적으로 "정체를 숨긴 인물"로 엮는다. 절대 규칙 2 위반이면서 **시민에게 정답을 주는 유출**이다.

TC-12(밤 로그)와 **원인이 다르다.** 입력을 깨끗하게 유지해도 발생하므로 입력 필터로는 못 막는다. 금지 표현 후보 — `정체를 숨긴` · `진짜 마피아` · `베일` · `미궁` · `여전히 감춰진`, 그리고 성별 추정(`그녀` · `그의`).

프롬프트 규칙("누가 마피아인지 판단하지 않는다")만으로는 안 걸러졌다. **문자열 검사를 붙일지, 표현을 열거해도 새는지를 먼저 봐야 한다** — 진술대조에서 "지켜지지 않는 규칙은 넣어도 값을 못 한다"를 겪었다.

**교집합을 빼지 않으면 검사가 무시당한다.** "생각해요" 같은 어절이 매 회차 걸린다. 검사는 조용해야 쓸모가 있다. 불리언이 아니라 **걸린 어절을 돌려준다** — 어디서 샜는지 보여야 고칠 수 있다.

검사를 `write_newspaper()` **안에** 둔 이유는 TC-12가 최우선 회귀 테스트라 빼먹을 수 없게 하려는 것이다.

### 길이는 `max_tokens`가 유일한 실효 상한이다

프롬프트에 "500자 이내"를 적어도 지켜지지 않았다. 실측 1토큰 ≈ 1.5자이므로 `max_tokens=300`이면 450자쯤에서 막힌다. **자동 검사는 500자 초과와 밤 로그 유출 둘뿐이고**, 역할 단정·톤·인용은 표현이 계속 바뀌어 목록으로 못 잡으므로 눈으로 본다.

## 8. 조작권 (17-4·17-5, [TC-15](테스트-체크리스트.md))

초코비가 R1 밤 `21:04:38`에 `NEWSPAPER_EDIT`을 썼다. 제1호는 조작본이어야 한다.

**AI 심판·방어권 결과는 조작 대상이 못 된다.** 실시간 이벤트로 이미 전원에게 나갔으므로, 부정하면 모두가 즉시 알아챈다. 사망자 줄과 처형·역할도 §4의 순서 덕에 손댈 수 없다.

노릴 것은 **신문만 말해주는 부분, 즉 토론 요약**이다.

```
원본  초코비 님은 곧바로 "제일 수상하다"며 손가락을 들었다.

조작  회의장의 시선이 딸기우유 님에게 모였다.
```

초코비는 R2 낮에 "저는 처음부터 딸기우유 씨를 믿었습니다"(`21:06:20`)라고 우긴다. **신문에 저 줄이 남아 있으면 바로 걸리므로 자기 이름을 지운다.**

픽스처가 여기에 맞물려 있다.

```
21:04:55  곰돌이: 근데 신문 내용이 좀 이상한데요 어제 흐름하고 안 맞아요
21:06:30  곰돌이: 방금 그 말 어제랑 완전히 다르잖아요 어제는 제일 수상하다고 했어요
```

곰돌이는 직접 들었으므로 조작을 알아챈다. **조작권이 진술대조권의 증거를 미리 지우려는 시도**가 되는 구조다.

여기에 딜레마가 하나 있다. LLM이 `"딸기우유 씨가 제일 수상해요"`를 화자까지 밝혀 인용하면 **그 문장이 곧 진술대조 TC-1의 근거 발화 `u2`다.** 조작의 표적이 선명해지는 것은 설계 의도와 맞지만, 조작권이 없는 판에서는 신문이 증거를 공짜로 뿌리는 셈이 된다 (→ §9 미결 2).

LLM은 조작에 관여하지 않으므로 프롬프트 대상이 아니고, **기대답안**에 원본/조작본 쌍으로 넣는다.

## 9. 남은 미결

### 1. 결과 한 줄에 득표를 넣을지 — 🔴 실측으로 문제가 확인됐다

제1호 1회분에서 **헤드라인이 사실과 반대로 나왔다.**

```
■ "시간 낭비"라는 딸기우유 님, 초코비 님의 지목으로 위기 맞아
```

실제 R1 투표는 `초코비=2 라면왕=2 소금빵=2 딸기우유=1`로 **딸기우유가 최저 득표**였고, 위기에 몰린 것은 호명당한 초코비다. 게다가 초코비는 "딸기우유한테 넣겠다"고 말하고 실제로는 소금빵에게 투표했다.

원인은 프롬프트가 아니라 입력이다. 결과 한 줄이 `처형 없음 (방어권_발동)`뿐이라 **득표가 안 들어가니 모델이 토론 분위기로 결과를 추측했다.** CLAUDE.md의 "서버가 아는 사실을 안 주면 추측하고, 추측은 과제 방향으로 기운다"가 그대로 재현됐다.

→ ~~최다득표자를 결과 줄에 추가한다~~ → **추가하지 않기로 확정 (2026-07-31).** 결과 줄은 `결과: {이름} 처형` / `결과: 처형 없음 ({사유})` 그대로 간다.

**대신 이 오류를 감수한다.** 신문은 게임 설계상 마피아가 조작하는 매체라 "신문을 100% 믿을 수 없다"가 이미 규칙 안에 있고, 그래서 헤드라인이 틀리는 것이 게임을 깨뜨리지 않는다. 이 기능 하나 때문에 게임 로직에 득표 조회를 요구하는 비용이 더 크다고 봤다.

**완화 후보 하나만 남겨둔다** — 프롬프트에 `주어진 결과 줄 밖의 투표 결과를 쓰지 않는다` 한 줄. 이미 "주어진 발언 밖의 사실은 쓰지 않는다"가 있는데 **투표 결과에는 안 걸렸다.** 회차를 늘려 같은 오류가 반복되면 그때 붙인다.

### 2. 인용이 진술대조 증거를 노출한다

상한 1~3개를 지켰는데도 3개를 다 쓰면 `u2`가 그대로 나갔다(§8). 상한을 2개로 줄일지, **인용을 짧게 자르도록**(`"제일 수상하다"`) 지시할지 골라야 한다. §2 예시는 후자로 썼다.

### 3. 커버리지 — 6명 중 3명이 안 나온 회차가 있다

제1호 1회분에서 라면왕·밤하늘·소금빵이 아예 등장하지 않았다. 빠진 것이 전부 다음 라운드에 다시 쓰이는 발화다 — 특히 `21:02:50` 소금빵 → 초코비 지목은 R2 토론 `21:05:05`의 핵심 근거이고, **아침에 붙는 사망자 줄이 소금빵인데 본문에 소금빵이 없으면 두 헤드라인이 서로 무관해진다.**

프롬프트로 "전원을 언급하라"고 하면 요약문으로 돌아간다. **사망 예정자를 알 수 없으므로(생성이 밤 살해보다 앞선다) 코드로도 못 챈다.** 관찰만 남기고 회차를 늘려 빈도를 본다.

### 4. 응답 시간 미측정

진술대조의 1.3~2.4초를 그대로 쓸 수 없다 — 500자 창작이라 출력 토큰이 몇 배다. 생성 창이 4~9초라 **이 값이 워밍업·재시도 설계를 좌우한다.** `write_newspaper()`가 `sec`를 돌려주므로 R1·R2·R3 각 3회에서 함께 받는다.

### 5. R2·R3 3회 실행

제1호만 봤다. 제2호는 처형·역할 공개 케이스, 제3호는 무사망 케이스라 사망자 템플릿 3종이 다 걸린다. `temperature=0.8`이라 흔들림이 진술대조보다 클 것이므로 3회는 최소선이다.

### 6. 무사망 문구

`■ 평화로운 밤이었습니다`는 잠정이다. 명세 17-7의 "평화로운 밤입니다~~"와 톤을 맞출지 정해야 한다 ([결정필요사항 B](결정필요사항.md)).

### 7. `ai-lab` 이식

노트북이 정본이고 **ai-lab**에는 아직 없다. 평문 출력이라 DTO가 없고, 프롬프트 `.st` + 사망자 조립 + 유출 검사만 옮기면 된다.
